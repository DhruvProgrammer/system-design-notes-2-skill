Each skill provides key concepts, a design procedure, trade-offs, and review checks to help AI agents and engineers reason through system design problems.

## How to Use

1. Choose the skill that matches your system design task.
2. Add its skill folder to your AI agent’s documented skills directory, or open the `SKILL.md` file and provide it as context.
3. Ask your agent to apply the skill to a design problem.

**Example prompts:**

- “Use the rate limiter skill to design distributed API throttling.”
- “Apply the chat system skill to compare WebSockets and long polling.”
- “Use the system design interview framework to structure my answer for a URL shortener.”

Agent skill discovery paths and installation steps vary by tool; follow the instructions for your AI agent.

## Skill Format

Each `SKILL.md` is organized as a reusable system design guide, with:

- YAML metadata describing the skill
- Key concepts and design components
- A step-by-step design procedure
- Important trade-offs and failure modes
- Checks for reviewing the proposed architecture
